# Checkpoint `orders-mongo`

## Antes

O espelho não cumpre esta fatia.

## Depois

URI do Mongo do espelho não é a porta 11008. Há coleção ou entidade de pedido.

## Como verificar

`scripts/academy/validate-checkpoint.ps1 -Checkpoint orders-mongo`

## Honesto

Se falhar, o capstone lista a dívida. Não apague o validador.
